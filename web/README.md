# Frontend

React, TypeScript and Vite. See the [repository README](../README.md) for what the page does and how to build the WebAssembly it loads.

```bash
npm install
npm run dev
npm run build
```

| Path | Contents |
|---|---|
| `src/engine` | Typed wrappers around the WebAssembly planner and kinematics modules |
| `src/components` | Robot and arm modes, the canvases, the timing tower and the benchmark section |
| `src/lib` | Canvas drawing, geometry helpers and theme tokens |
| `src/wasm` | Generated by `wasm-pack`; do not edit by hand |
| `public/bench-results.json` | Copy of `../bench/results.json`, loaded by the benchmark section |

The design direction is recorded in [DESIGN.md](DESIGN.md).
