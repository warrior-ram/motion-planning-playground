# Demo 1 — Motion Planning Playground: interface contract

Shared, frozen contract between the three parallel workstreams. Do not change it unilaterally.

## Repo layout and ownership

| Path | Owner |
|---|---|
| `Cargo.toml` (workspace root) | already written, do not edit |
| `crates/planner/**` | Agent A (mobile-robot planners + benchmark) |
| `crates/kinematics/**` | Agent B (arm FK / IK / joint-space planning) |
| `web/**` except `web/src/wasm/**` | Agent C (frontend) |
| `web/src/wasm/planner/` | generated by Agent A's wasm-pack build |
| `web/src/wasm/kinematics/` | generated by Agent B's wasm-pack build |
| `bench/**` | Agent A |

Build commands (run from repo root):

```
wasm-pack build crates/planner    --target web --release --out-dir ../../web/src/wasm/planner
wasm-pack build crates/kinematics --target web --release --out-dir ../../web/src/wasm/kinematics
```

Each crate must have `crate-type = ["cdylib", "rlib"]`, and depend on `wasm-bindgen`, `serde` (derive) and `serde_json`. Randomness must be seeded and deterministic (use a small in-crate PRNG such as xorshift/splitmix; no `getrandom`).

## Coordinates

World units, origin top-left, +x right, +y down (canvas convention). Default world is 1000 x 640. Angles in radians; joint angle 0 points along +x, positive angles rotate clockwise on screen (because +y is down) — i.e. standard `x += L*cos(θ), y += L*sin(θ)`. Joint angles are relative to the previous link.

Obstacle (shared shape):

```json
{ "kind": "rect", "x": 0, "y": 0, "w": 10, "h": 10 }   // x,y = top-left corner
{ "kind": "circle", "x": 0, "y": 0, "r": 10 }          // x,y = center
```

All functions take a JSON string and return a JSON string (camelCase keys). On bad input return `{"error": "message"}` instead of panicking.

## Crate `planner` (Agent A) — wasm exports

### `plan(req: &str) -> String`

Request:

```json
{
  "algorithm": "astar" | "rrt" | "rrtstar",
  "width": 1000, "height": 640,
  "obstacles": [Obstacle],
  "start": {"x": 80, "y": 320}, "goal": {"x": 920, "y": 320},
  "robotRadius": 12,
  "seed": 1,
  "params": {
    "gridSize": 10,          // A* cell size (8-connected, octile heuristic)
    "maxIterations": 20000,  // RRT / RRT*
    "stepSize": 25,
    "goalBias": 0.05,
    "goalTolerance": 20,
    "rewireRadius": 60       // RRT* neighbourhood
  }
}
```

Every `params` field is optional with the defaults above. Collision = robot disc (radius `robotRadius`) against obstacles and world bounds; RRT edges must be checked along the segment.

Response:

```json
{
  "found": true,
  "path": [{"x":..,"y":..}],     // start..goal, world coords; [] if not found
  "pathLength": 1234.5,          // 0 if not found
  "nodesExplored": 812,          // A*: closed cells; RRT/RRT*: tree nodes
  "iterations": 1500,
  "events": [Event]              // ordered exploration log, for animated replay
}
```

Event (one unified shape so the frontend draws edge parent -> node):

```json
{"k":"expand","x":..,"y":..,"px":..,"py":..}            // A*: cell closed (px,py = parent cell centre; equals x,y for start)
                                                         // RRT/RRT*: node added to tree with parent
{"k":"rewire","x":..,"y":..,"px":..,"py":..,"opx":..,"opy":..}  // RRT* only: node's parent changed from (opx,opy) to (px,py)
{"k":"frontier","x":..,"y":..}                           // A* only: cell pushed to open set (optional, cap volume)
```

Cap `events` at 20000 entries (keep the earliest). Planning time is measured by the frontend with `performance.now()` around the call, not returned.

### `benchmark_maps() -> String`

Returns the fixed set of 20 maps used by the benchmark, as JSON:

```json
[{"id":"m01","name":"Open field","width":1000,"height":640,"start":{..},"goal":{..},"obstacles":[Obstacle]}]
```

Generated deterministically (mix of hand-designed: corridors, maze, bug-trap, narrow passage; and seeded random clutter). The frontend uses these as presets.

### Benchmark

Native binary `cargo run -p planner --release --bin bench` runs all 3 algorithms over the 20 maps (RRT/RRT* averaged over 10 seeds each), measures time with `std::time::Instant`, and writes `bench/results.json` and `bench/results.md` (table: map, algorithm, success, time ms, nodes explored, path length, plus a summary table per algorithm with success as "x of N").

## Crate `kinematics` (Agent B) — wasm exports

Arm: planar serial chain, 2 or 3 revolute joints.

### `fk(req: &str) -> String`

```json
{ "base": {"x":500,"y":320}, "links": [127,99,64], "angles": [-1.2, 0.5, 0.3] }
-> { "joints": [{"x":..,"y":..}] }   // length = links.len()+1, includes base and end effector
```

### `ik(req: &str) -> String`

```json
{ "base": {..}, "links": [..], "angles": [..current, used as seed..],
  "target": {"x":..,"y":..},
  "limits": [[-3.14,3.14], ...],      // optional per-joint min/max
  "maxIterations": 100, "tolerance": 0.5 }
-> { "angles": [..], "joints": [..], "reached": true, "error": 0.3, "iterations": 12 }
```

Use damped-least-squares Jacobian IK (fall back to closed-form for 2 links is fine). Unreachable targets: return the best stretch toward the target with `reached: false`. Must be fast enough to call every pointer-move (<1 ms).

### `plan_arm(req: &str) -> String`

Joint-space motion planning around obstacles.

```json
{ "base": {..}, "links": [..], "obstacles": [Obstacle], "linkThickness": 8,
  "start": [angles], "goal": [angles],
  "algorithm": "rrt" | "rrtstar", "seed": 1,
  "params": {"maxIterations": 10000, "stepSize": 0.15, "goalBias": 0.1, "goalTolerance": 0.1, "rewireRadius": 0.5} }
-> { "found": true, "path": [[angles]], "nodesExplored": .., "iterations": ..,
     "events": [{"k":"expand","q":[..],"pq":[..]} | {"k":"rewire","q":[..],"pq":[..],"opq":[..]}] }
```

Collision: each link is a capsule of `linkThickness` against obstacles; check interpolated along joint-space edges. Angles wrap to (-π, π]. `path` should be densified so consecutive configs differ by ≤ 0.05 rad per joint (for smooth animation).

### `arm_config_valid(req: &str) -> String`

`{ base, links, obstacles, linkThickness, angles } -> { "valid": true }` — used by the UI to colour the arm red on collision.

## Frontend (Agent C)

Vite + React + TypeScript app in `web/`, `motion` (framer-motion successor) installed. Imports the generated packages:

```ts
import initPlanner, { plan, benchmark_maps } from "./wasm/planner/planner";
import initKin, { fk, ik, plan_arm, arm_config_valid } from "./wasm/kinematics/kinematics";
```

Wrap them in `web/src/engine/` typed modules (JSON.parse/stringify + types from this contract).
